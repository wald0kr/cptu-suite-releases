# CPTu Suite – releases

Windows builds of CPTu Suite, a tool for processing CPTu (piezocone) soundings.

**Download:** go to [Releases](https://github.com/wald0kr/cptu-suite-releases/releases/latest) and download `CPTuSuite-vX.Y.Z.exe`, then run it. No Python installation needed.

Windows SmartScreen may warn on first run because the executable is unsigned. Choose **More info**, then **Run anyway**.

The tool is for comparing correlations and supporting engineering judgement. It does not replace checking the input data and interpreting the results yourself.
